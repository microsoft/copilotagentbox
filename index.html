Sobre o Projeto

O que é o Copilot Agent Box?

O Copilot Agent Box é uma coleção curada de agentes de IA prontos para uso com o Microsoft 365 Copilot. Nosso objetivo é acelerar a criação de soluções inteligentes, oferecendo templates, documentação completa e boas práticas.

Templates Prontos

Agentes prontos para uso imediato que podem ser facilmente adaptados às suas necessidades.

Documentação Completa

Cada agente possui documentação detalhada de arquitetura, uso e exemplos práticos.

Integração M365

Totalmente compatível com o ecossistema Microsoft 365 Copilot e suas ferramentas.

Open Source

Código aberto e contribuições da comunidade são muito bem-vindas!
